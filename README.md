# Notes Authentication Prototype

A Flutter and Firebase prototype focused on email/password authentication.

## Features

- Login and registration screens
- Firebase integration
- Cross-platform Flutter project structure

## Stack

Flutter · Dart · Firebase Auth

## Run locally

```sh
flutter pub get
flutter run --dart-define-from-file=firebase.local.json
```

See [SECURITY.md](SECURITY.md) for local Firebase configuration and API-key handling.

## Project status

Notes create/read/update/delete functionality has not been demonstrated in this source. The repository is an authentication prototype.
